# ForCats — КР №3

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Проект создан на основе собственной КР №1 `kr1-html-css-shop`. Оригинальный дизайн и товары сохранены. Bootstrap не используется.

## Страницы проекта

- `index.html` — главная страница магазина.
- `catalog.html` — каталог товаров и фильтры.
- `product.html` — карточка товара, характеристики, отзывы и форма добавления отзыва.
- `order.html` — учебная форма оформления заявки.
- `contacts.html` — контактная информация.
- `about.html` — информация о магазине (дополнительная страница).

## Адаптивная вёрстка

- `css/style.css` содержит основные стили и визуальное оформление магазина.
- `css/responsive.css` содержит адаптивные правила и подключается после основного файла стилей.
- Используются медиазапросы для экранов до 1023, 767 и 479 px.
- Сетка карточек построена по принципу Mobile First: одна колонка на узких экранах, две колонки от 480 px и три колонки от 1024 px.
- На узких экранах фильтры каталога располагаются над списком товаров.
- Страница товара перестраивается в одну колонку.
- На телефонах до 767 px используется сворачиваемое меню с кнопкой и атрибутом `aria-expanded`. Меню закрывается клавишей Escape и нажатием вне его области.
- На планшетах навигация переносится на отдельную строку.
- Отступы по краям страницы задаются через `--page-gutter` и `clamp()` с учётом ширины экрана.
- Для фотографий товаров и главного изображения используются `srcset` и `sizes`. В `images/responsive/` находятся WebP-версии шириной 320, 640 и 960 px; браузер выбирает подходящий вариант.
- Таблица характеристик адаптируется к мобильным экранам: предусмотрено карточное представление, а при сохранении табличной структуры прокрутка ограничивается контейнером, не расширяя всю страницу.
- Формы, модальное окно, отзывы и плавающий чат адаптированы для телефонов.
- Интерактивные элементы имеют удобные области нажатия.

## Доступность

- Добавлена ссылка пропуска навигации «Перейти к содержимому» (`skip-link`).
- Для активного пункта навигации используется `aria-current="page"`.
- Для клавиатурного управления предусмотрено видимое состояние `:focus-visible`.
- Кнопка мобильного меню связана с состоянием через `aria-expanded`; меню закрывается по Escape и при нажатии вне него.
- Изображения каталога снабжены осмысленными альтернативными описаниями `alt`.
- Поля форм связаны с элементами `label`; обязательные поля отмечены атрибутом `required`.
- Заголовки строк таблицы характеристик размечены через `th scope="row"`.
- Для уменьшения анимации поддерживается настройка `prefers-reduced-motion`.
- Статус отправки учебной формы выводится через `textContent`.
- Прокручиваемые области доступны для клавиатурной навигации.

## Дополнительные функции

- На странице товара доступны демонстрационные отзывы и форма добавления отзыва с оценкой. Новые отзывы сохраняются локально в браузере через `localStorage`.
- На странице заявки доступны выбор товара и количества, выбор способа получения, проверка формы и автоматический пересчёт суммы.
- Поддерживаются промокоды `MEOW10` (скидка 10%) и `KITTY15` (скидка 15%).
- Сохранены дополнительные страницы «О нас», чат и исходный визуальный стиль магазина.
- Серверная часть и платёжная система не подключены. Данные учебной формы не отправляются на сервер.

## Запуск и ручная проверка

Проект можно запустить через расширение Live Server в Visual Studio Code или локальным сервером из корневой папки:

```bash
python3 -m http.server 5500
```

После запуска откройте `http://localhost:5500`.

Проверьте страницы на ширинах 360, 375, 430, 768, 1024, 1280 и 1440 px. Дополнительно проверьте:

- отсутствие горизонтальной прокрутки всей страницы;
- работу мобильного меню, включая закрытие по Escape и нажатию вне меню;
- загрузку адаптивных изображений во вкладке Network → Img;
- переход по интерактивным элементам клавишей Tab и видимость фокуса;
- карточное представление таблицы характеристик на телефоне;
- заполнение и проверку формы заявки;
- добавление отзыва и сохранение его после перезагрузки страницы.

### Исправления по результатам аудита

- Основной цвет интерактивных элементов в `css/style.css` изменён на `--color-primary: #b12c77` вместо `#dc5ea6`. Контраст с белым составляет примерно 6.01:1, со светло-розовым фоном `#fff5fa` — примерно 5.63:1.
- Прежний розовый `#dc5ea6` сохранён для логотипа через `--color-brand-pink`, чтобы не менять оформление шапки.
- Фон бейджа «Новинка» изменён на `#147a2a`; контраст с белым составляет примерно 5.46:1.
- В `index.html` добавлены метаописание `meta name="description"` и более конкретный заголовок `title`.

Баллы Lighthouse могут немного отличаться при повторном запуске из-за условий измерения, поэтому в README приведены именно значения из сохранённых отчётов от 31.10.2026.
